# 百炼真实接口验证与问题记录

日期：2026-10-27。结论：回答模型与向量接口已接通，25项功能及边界测试通过；回答语义质量尚未验收。当前仍为本机原型。

## 1. 验证条件

使用本机保存的百炼配置：回答模型`qwen-flash`，向量模型`text-embedding-v4`。真实建立26个证据块的向量索引，并通过网页完成了一次模拟报告问答。密钥、业务空间接入地址和本机运行数据库不进入本文或仓库。

语料为5份官方资料摘要、明确标注的模拟规格及规范、一份模拟报告，以及产品流程约定。使用快照`BOOTSTRAP-20261026-01`；语料SHA-256为`cb67946e0a0f0a6732214b6488b3b5c1a6ef0a2213516ef5e5bc32b19a28b1ef`。未使用公司原始资料，标准技术条款判定仍未启用。

开发集共24题、41个必要证据组，top-k为6。题目及参考标签只由评测脚本读取；应用与模型输入不读取参考答案。标签由作者草拟，专业复核和独立测试集尚未完成。

## 3. 本轮修正

| 发现 | 处理 | 验证 |
| --- | --- | --- |
| 标准号只出现在公告正文时被误判无资料 | 可用标准识别同时检查标题与正文 | 新增公告正文识别回归用例 |
| 问实施日期并询问条款能力时，日期一起被拒答 | 缺全文时保留题录中已知日期，仍明确缺少技术条款 | 程序提取日期及引用校验通过 |
| 引用真实但把0.68 s误判为满足500 ms | 增加Decimal秒到毫秒换算辅助；提示词要求统一单位后比较 | 后续实际返回能得出680 ms超出演示限值；不保证所有重跑均正确 |
| 报告记录被召回，对应规格或另一类记录要求遗漏 | 按任务与版本权限补充关联规格、冲突规则、外观及恢复方式要求 | 关联规格未进入初排时仍需被补入，25项回归测试通过 |
| 把程序换算字段或题设当引用ID | 明确引用候选；保留严格ID校验 | 错误引用仍可能发生，程序会拦截，未放宽校验 |

关联依据规则目前针对本样本包的文档关系配置，扩充真实知识库时需要维护来源关系并重新验证。单位辅助只负责明确数值的秒到毫秒换算，不负责修复模糊字符，也不是完整技术判定引擎。

## 4. 尚未解决的质量问题

| 用例 | 最后运行中的实际问题 | 后续验收关注点 |
| --- | --- | --- |
| QA-12 | 把“C1的5 V输出角色”写成“C1充电输入的5 V输出角色”，输入输出角色混淆，引用检查未识别 | 角色与电压范围必须来自结构化范围；不把未配置输入说成已覆盖 |
| QA-16 | 正确说明演示不能出证或放行，但状态仍为依据不足；限制说明又引入2026版标准要求 | 回答状态与结论一致；只列当前任务实际缺失的条件，避免跨时点补要求 |
| QA-17 | 最后一次引用`unit_calculations`作为证据ID，结果被程序拦截 | 程序换算只能辅助推导，引用必须落在本次授权证据；失败保留检索结果 |
| QA-18 | 已能按模拟RevB比较5.31 V与上限，但未充分强调报告依据冲突下的条件性结论 | 同时呈现报告依据与已选规格，保留待核实状态和负责人复核 |
| QA-21 | “未通过判别”措辞可能被理解为试验失败，实际依据是记录不足 | 使用“证据不足、不能判通过”，避免与明确超限或试验失败混用 |

以上是助手对实际输出的审查记录，仍待专业人员复核，不作为正式人工验收标签。全部用例的`final_human_decision`保留为空。

QA-17在前一轮通过引用校验，最后一轮被拦截，两次规范化请求体SHA-256均为`61c2a35cc1ae7ee09ae241b3715c2e66e1548fde26289173306b67879785172e`。相同模型ID、提示词和请求内容也可能得到不同输出；本轮保留了失败，没有以重跑成功覆盖失败。模型使用服务方别名，服务端具体版本未锁定。

检索全部命中、JSON合法、引用存在都不能证明结论正确。当前不发布“回答准确率”，也未测量评审工时、遗漏减少或改板减少。
