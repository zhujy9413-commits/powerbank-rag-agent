# 08-P0修复回归与第二批留出评测

v0.3 · 2026-10-28。三个P0已补上保守处理：未知编号不再静默消失，图片未核验时停检，局部条件未绑定时不能默认继承全局条件。102项自动回归通过；另取20份新模拟PDF、40页，先冻结再首次评测，20/20个场景满足期望。

20/20代表正确比较、提示或停止行为符合本轮协议，不表示全部记录解析成功。文字记录匹配190/205条；15条未批准或缺失编号的记录没有自动映射，但均进入审计并触发停检。没有实现OCR或真实标准验收。

## 三个P0的具体变化

| 问题 | 修复后的行为 | 当前使用代价 |
| --- | --- | --- |
| 编号遗漏 | 在已识别表头、同行及分隔列中，按记录结构发现未知、中文、长编号及缺失编号；保留候选、原文、影响单元和未映射诊断 | 未批准格式不自动进入数值比较；需要提供清晰的受支持记录，不能把“有提示”称为已解析 |
| 文字与图片混排 | 检查PDF实际绘制操作，覆盖XObject、嵌套Form及内联图片；图片内容未核验或资源检查失败时，10个配置单元未检查 | 当前不区分装饰图与记录图，有实际图片也会整体停检；未绘制的资源不误报 |
| 局部条件遗漏 | 审计未被明确绑定的条件声明、脚注、备注及局部工况；明确记录ID或端口时定位影响范围，无法确定时全部停止 | 保留待核对说明，不猜测局部条件值及作用范围；有限语法之外仍需人工澄清 |

数值修正不能绕过这些覆盖阻塞。图片仅提供PDF页定位，未生成图片内的虚构文字引文。原有UI和Excel使用统一诊断及未检查状态，不将其算作配置项通过。

负载、样机等尚未支持的行内条件也会因未绑定声明保守停止；没有新增这些维度的正式比较规则。当前仍仅核对PB-DEMO-01、A1/C1、5 V输出、单口的模拟短路保护已有记录。
