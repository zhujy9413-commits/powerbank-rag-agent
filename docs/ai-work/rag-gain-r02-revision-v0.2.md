# AI Work R02 评分口径修订与核验报告

版本v0.2 · 2026-10-29。R02已改为“前5条实际返回精度”，配套独立种子相关性标注与参考评分函数。修订解决原分母使当前开发查询无法达到80%门槛的问题；本轮核验评分契约、标注绑定和材料不变性，没有执行候选检索、模型生成或应用评测。

## 修订内容与生效范围

原口径以min(5,授权候选数)作分母。当前每个来源都有至少5个授权候选，但多数查询只有2至3个相关片段，因此即使完整返回正确证据也达不到80%。原预检的245个正例查询与来源组合均存在这一问题。问题与修订发生在任何候选实测之前，没有据分数调整标签或更换样本。

新口径命名为前5条实际返回精度P_returned≤5，明确区别于固定5槽Precision@5。对正例查询与一个来源命名空间，L为最终补充检索在评分校验前的原始种子顺序，m=min(5,len(L))。得分=前m槽中相关且身份/逐字原文有效的槽数÷m；m=0记0。

A1至A4每个留出轮次分别计算要求与报告的等权查询宏平均，各≥80%。A0无补充排序，R02不适用，仍评R01/R03；A3/A4使用A1/A2的原始检索排序，不能靠生成校正删掉检索错误。该门槛针对新定义，不能与旧口径混算；当前没有旧口径的真实RAG分数。

| 项目 | 当前口径 |
| --- | --- |
| 少返回 | 不补不存在的空槽；完整性仍由R01/R03限制，不以R02单独决定采纳 |
| 重复槽 | 同chunk ID，或同源路径、版本、来源角色及原文内容的重复，只有首次位置有效时可计相关；后续占槽记0 |
| 错误槽 | 未知ID、越权、错任务/命名空间/角色/版本/定位/条件或非逐字引文占槽记0，并单列控制异常 |
| 扩展片段 | 预注册扩展不进入种子精度；自然检索到且预标相关的表头可作为种子 |
| 返回超过5条 | 只计前5，保留完整列表并标记配置违规，不能用截断分数宣布实验有效 |
| 正例空返回或失败 | 明确已执行的空返回/检索失败记0，仍在固定查询宏平均分母内 |
| 未运行或标签争议 | 缺运行记录/日志、未标注、争议或语料快照不符记未完成，不计算可用于通过的部分均值 |
| 缺证负例 | 不填0或1，不进入精度宏平均；按固定负例清单另验100%正确收敛 |
| 上游检索处理 | 授权过滤、RRF融合和配置阈值按冻结检索方案执行；评分器不得再删错项或去重来美化最终返回列表，应用不能读取qrels |

## 独立相关性标注

[开发种子qrels](../../data/ai-work-rag-gain-v0.2/qrels-dev-v0.1.json)单独登记124个查询的248个来源组合，其中245个正例、3个报告缺证负例，共4971个候选相关性标签。每个授权候选均有0/1标签，输入语料和原完整性标注均绑定SHA-256。未判定或有争议的标签不自动当0或1。

本版采用保守相关集：已核验必要组中能帮助回答本项的片段登记为相关，其余授权候选登记为不相关；可选相关补标为0。相关性是种子级判断，必要组仍按AND/OR核对完整性，不能把“有一个相关片段”当“证据组齐备”。标签为同作者内部核对，专业及外部独立复核仍待完成。

| 片段类型 | 相关性边界 |
| --- | --- |
| 端口/字段测量 | 相同数值不使A1与C1互换；其他字段不能借相同数字成为本项依据 |
| 条件和表头 | 仅引用真实前置说明及明确单位表头；不能为缺值补单位或猜归属 |
| 9 V或输入角色 | 只有预登记contrast_only的查询可将其作工况对照；禁止替代本次5 V输出测量 |
| 背景合格说法 | 仅对背景一致性核对查询相关；不能证明缺失的外观/恢复方式记录存在 |
| 报告RevA声明 | 只支持版本冲突事实；不得充当选定RevB的规范要求 |
| 无关任务附件 | 每报告20个干扰块全部记0，未删减或新增材料来凑得分 |

3个报告缺证负例保持原标注。原始检索可以返回噪声，但最终须拒绝为测量依据，保留evidence_insufficient、接受证据为空、不伪造“没有记录”的证明、不宣称物理测试未执行。未提供最终处理记录记未完成，不以空列表冒充正确拒答。权限及引用门禁继续独立检查。

## 手工可核对的边界例子

| 输入 | R02结果 | 联合判断 |
| --- | --- | --- |
| 两条不同的相关种子 | 2/2=100% | 再核对全部必要组，不能据此宣布RAG增益 |
| 只返回一条相关种子，另有必要组未覆盖 | 1/1=100% | 完整性不足；R01/R03继续约束 |
| 2条相关、1条噪声 | 2/3约66.7% | 不因评分器删除噪声而变成100% |
| 同一相关种子重复两次 | 1/2=50% | 重复占据原槽位 |
| 正例明确空返回 | 0 | 留在宏平均固定分母内 |
| 报告缺证、原始返回噪声但最终全部拒绝 | 精度不适用 | 独立核对正确缺证处理 |
| 身份或引句不符 | 该槽记0 | 控制异常不能被其他正确片段或均值掩盖 |
| 缺运行日志或标签未决 | 未完成 | 不缩小分母后宣布通过 |

宏平均按查询等权计算。例如一个查询1/1，另一个0/4，宏平均为50%，不是合并槽位后的20%。要求与报告不合并，各留出轮次不挑选。固定正例分母和负例数量随资产冻结；失败、少返回或未运行均不能事后删除。

## 核验记录与结论

[26个参考评分契约测试](../../eval-results/rag-gain-r02-scoring-tests-v0.2.txt)覆盖短返回、空返回、重复ID/同源文本、未知ID、8项身份元数据、伪造引句、越权角色、扩展混入、超5条、A0不适用、语料漂移、未标注、负例及宏平均分母。它们使用人工构造排序，未调用应用或服务方。

[机器核验记录](../../eval-results/rag-gain-r02-validation-v0.2.json)的2397/2397项核验通过，逐一检查相关性标签、来源哈希、原必要组保留、三类证据角色，以及旧分母问题是否复现、新分母是否可达。245个正例的理想排序仅按金标构造用于验证算术；其可达100%不代表实际召回、精度或模型能力。3个负例另核对收敛契约。

开发包的93个内容资产、既有88份冻结材料、原开发ZIP、旧协议与历史结果保留原字节，应用及锁定来源未变。R01≥95%、R03每轮22/24与净增3份、S01至S03、M01、P01和C01的门槛均未调整。80%的R02数值门槛保留，但采用本版新分母及标签契约，不能把本轮视为已经通过实际增益验收。
