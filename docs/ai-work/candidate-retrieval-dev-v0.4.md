# AI Work 候选检索链路实现与开发验证

候选模块v0.4 · 2026-10-29。已实现隔离的A1关键词补证据、可注入向量的混合检索接口、双来源隔离、上下文扩展和引用校验。12份开发PDF已实际执行原规则与补充检索，4个离线异常夹具已执行适配器契约。完整回归202项通过，其中候选模块35项、R02评分26项；另有2069/2069项执行与材料完整性核验通过。

当前可通过CLI复现开发实验，普通应用页面仍运行v0.4.3原规则流程。A1开发指标达到本轮检索数值门槛，但两个要求侧一致性查询未覆盖齐全，候选尚未冻结。真实Embedding与模型生成调用为0；A2内容运行全部显式降级为关键词，不能据此认定混合检索有效或宣布RAG增益。

## 实现范围与调用边界

| 组成 | 已实现行为 |
| --- | --- |
| 输入与权限 | 只读当前开发application-inputs及其原文；按任务授权、角色、选定版本、发布状态与来源角色过滤。依据停用或原文无法定位时，在新检索前拦截 |
| 要求与报告 | 两个命名空间独立检索；要求限定选定依据，报告限定本任务。报告RevA声明只支持版本事实；其他条件记录只作条件对照 |
| A1 | BM25各取前12候选，最终每来源最多5个种子；同分按稳定来源ID排序。端口、字段及来源路由与领域词汇扩展只读查询和原文 |
| 混合接口 | 注入向量批次后校验数量、有限数、维度、范数及模型身份；等权RRF常数60。文档向量缓存绑定任务、授权、版本、源内容和模型，查询结果不缓存 |
| 降级与引用 | 向量缺失、失败或身份漂移显式降级；返回完整原始种子顺序。仅按预注册context_ids扩展，每种子最多1条，扩展单列。返回前再核对授权、身份及原文 |
| 原结果保护 | 补充结果作为独立sidecar保存；12份报告的完整原规则载荷哈希均保持一致，缺证、停检、条件及历史原样保留 |
| 异常适配器 | 非法引用最多校正1次后回退；单次20秒、总任务45秒的预算通过虚拟时钟注入检查。结构有效草稿仍待语义复核，不产生新判定 |

原文定位只忽略PDF换行等空白，不改文字或数字；R02的引句继续逐字匹配冻结片段。检索候选可定位不等于业务结论已核实，补充说明不改写规则结论。在线生产传输的超时执行及费用账本仍需后续接入验证。

应用阶段在独立子进程运行，禁止读取qrels、reference-annotations、author-source及既有eval-results；完成原始输出后，父进程才加载评分标注。全部开发执行禁用网络，未读取本机密钥、用户任务或正常数据库。应用代码未引用参考标注ID或按case_id指定召回目标。输入仍使用已核验的人工分块，不宣称新增了通用PDF自动分块能力。

## 残余缺口与冻结条件

| 开发查询 | 缺口 | 后续处理 |
| --- | --- | --- |
| RG-GAP-DEV-02 的 SPEC-VERSION 要求侧 | 仅覆盖1/2组；未召回选定RevB的电压规范引文 | 核验“版本核对”到选定规格正文的路由，补行为验证，不直接在代码写入金标ID |

开发宏平均R01与R02达标不能抹掉这两项缺口。先完成上述语义关联，再做专业复核及真实Embedding预检与授权。候选、排序、评分器和模型配置冻结后，才制作32个留出场景。R03净增益、真实A2、A3/A4说明、M01人工可用性、P01全链路时延和C01真实成本均待验。本轮没有发布候选到正常应用页面或知识库。

## 复现与核验证据

在项目根目录执行`python3 scripts/evaluate_candidate_dev.py --route --output tmp/candidate-new-run.json`，会新建临时数据库、实际解析12份冻结PDF，再离线执行4个夹具。输出路径必须不存在；调试记录只追加。`--route`启用当前共享路由，省略该选项可检查未路由的BM25路径；历史轮次应检出对应提交复现。

运行`python3 -m unittest discover -s tests -v`检查全量测试；当前[202项回归日志](../../eval-results/candidate-regression-v0.4.txt)包含[35项候选测试](../../eval-results/candidate-unit-tests-v0.4.txt)。`python3 scripts/validate_candidate_dev.py --output tmp/candidate-new-audit.json`复核执行、来源与历史不变性，当前[核验记录](../../eval-results/candidate-dev-validation-v0.4.json)为2069/2069通过。

原开发93项资产、88份既有冻结材料、86份之前的结果文件、原ZIP及锁定规则/知识来源保持原字节。v0.2协议和台账保留R02修订时快照，本轮实际执行以新的开发运行清单及最终结果为准。[验证方案](rag-gain-validation-plan-v0.1.md)的验收门槛未修改；32个留出场景仍未制作。
