# 跨行摘要与单位归属修复回归及新样本评测

2026-10-28，模拟原型v0.4。修复同页跨行摘要被重复当作孤立单位的问题，并约束记录、摘要与跨页续行的单位归属。129项自动测试通过；代码冻结后另建20份新PDF、40页，首次20/20满足预设场景期望，200/200条文字记录匹配。本轮只验证PB-DEMO-01受控模拟输入，专业复核待完成。

## 修复行为

原HO-17中，摘要“S41：A1保护响应 0.137”与下一行“s”已经被摘要正则识别，但逐行审计又将s误判为孤立单位，挂到上一页A1恢复方式。v0.4在同一轮扫描中解析摘要并记录占用的原文片段；摘要与单位只归属一次，保留实际换行、页码和文件摘要。

| 输入 | v0.4处理 |
| --- | --- |
| 同页连续两三行的摘要标题、数值和ms/s | 合并为一个摘要，独占单位行归属对应摘要编号 |
| 摘要后紧邻“条件：…” | 条件绑定摘要，不能误改上一条恢复方式记录 |
| 同对象同条件摘要与明细值不同 | 保留双方，标记一致性冲突，明细为条件性结果 |
| 摘要条件不一致或自身矛盾 | 不认定为同条件数值冲突，一致性保持未检查 |
| 摘要缺单位、跨页、被表头或下一条记录打断、单位未配置 | 明确摘要诊断，停止受影响响应项比较；不借用别的记录单位 |
| 同记录相邻的数值和单位行 | 只连接兼容字段的单位，记录精确归属 |
| 明确跨页续行且上一页只有一个待补的页尾记录 | 连接并保留两页片段；已填单位、多个候选或本页已有记录时不猜测 |
| 其余孤立单位 | 提示归属未核实；可唯一定位的未声明页尾记录只停对应项，否则停全部10项 |

解析器新增摘要候选及独占单位行归属审计。版本升级为controlled-pdf-v0.4 / synthetic-short-circuit-v0.4；旧解析快照须重新导入PDF，历史结果仍保留。生产运行不增加OCR、Pillow或模型依赖。
