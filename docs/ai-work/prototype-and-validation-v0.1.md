# AI Work｜逐项评审原型与测试报告

版本 v0.1 · 2026-10-28。已实现本机模拟报告流程；正式标准规则和真实业务验收尚未完成。

2026-10-28 后续进展：新增受控PDF变体、解析覆盖及条件核对，最新80项回归与支持边界见[模板变体与条件冲突回归](pdf-variants-and-conditions-v0.2.md)。本文保留首版62项测试的历史记录。

## 本轮完成的流程

选择或上传同模板模拟 PDF → 查看解析与原文 → 确认报告、依据与范围 → 逐项核对 → 人工复核 → 导出 Excel。

入口与原有知识问答共用本机应用，左侧新增“报告逐项评审”。两个模块各有工作页面；上传的评审报告只保存在任务内，不写入全局知识库。

本轮直接读取四页 PDF 提取文字与表格记录，没有用此前的文字对照或参考答案冒充 PDF 解析。支持范围限定为 PB-DEMO-01 模拟报告模板，文本版 PDF 不超过 2 MB、12 页、提取文字不超过 80,000 字符。这些是本版工程限制，尚未用代表性业务语料确定通用能力。

## 检查范围与依据

| 维度 | 本版范围 |
| --- | --- |
| 产品 | PB-DEMO-01 虚构充电宝整机 |
| 对象与条件 | A1、C1；5 V 输出角色；端口短路保护已有记录 |
| 已配置检查 | 每端口的响应时间、恢复电压、壳温变化、外观文字、恢复方式，共10个单元 |
| 一致性检查 | 对应端口摘要与明细、本次采用依据与报告填写版本 |
| 本次采用 | 模拟规范 SYN-QA-SC-1.0、模拟规格 SYN-SPEC-PB01-RevB |
| 未配置 | 充电输入、其他电压档、多口组合、其他保护功能 |

响应≤500 ms、恢复电压4.75—5.25 V（含边界）、壳温变化≤12 K均来自已发布模拟资料。代码从本次授权依据文本读取数值；没有将这些数值写成国家标准条款。公开标准摘要不参与真实限值判定。

## 逐项检索与判定怎样工作

1. 校验模拟模板和适用身份，提取 PDF 页文字、记录ID、端口、字段、原始值与定位；保存文件 SHA-256。
2. 用户核对提取结果与范围。解析修正必须有原因；原值、原文、修正值、操作者和时间分别保存。
3. 确认时固定输入修订、知识发布、依据原文和规则版本。当前只允许选择已配置的 RevB 模拟规则，不提供任意阈值编辑。
4. 每个预期单元单独构造端口与字段查询，复用关键词排序，再扫描当前任务全文，以记录ID、端口和字段建立映射。缺证不能只凭一次 top-k 召回判断。
5. 要求证据与报告证据使用独立身份。程序进行单位换算、闭区间比较、温差计算与明确文字记录核对；来源片段必须能在本次原文中找到。
6. 检查结果、检索页范围、原始证据、耗时及执行代码摘要随运行保存。专业最终判断仍由人工记录。

本模块复用知识库的发布、权限、版本与来源身份，并新增任务 PDF 索引和逐项证据检索。当前判定和解释使用确定性规则，未请求生成模型，也未为本轮报告另建向量索引。已有智能客服仍保留完整的混合检索与模型回答链路；不能把本次规则运行称为新增的模型评测。

## 页面操作与结果保存

| 操作 | 已实现行为 |
| --- | --- |
| 使用模拟报告 / 上传同模板 PDF | 新建独立任务；提取文字并显示页码与文件摘要；不适用模板拒绝处理 |
| 确认输入与依据 | 生成新的不可变输入修订；未确认时不能开始检查 |
| 修改解析 | 只修正唯一定位的字段；缺失记录需补充报告；未确认修改不能触发新检查 |
| 开始逐项检查 | 同一幂等标识返回同一次运行；不同输入版本不能重用标识 |
| 查看发现 | 保留未发现问题、不符合、冲突、证据不足与执行失败；支持筛选待复核项目 |
| 人工复核 | 确认系统结果、排除系统结果、暂无法确认均需理由；追加版本记录，不改写系统结论 |
| 输入修订后重跑 | 新旧运行分别保存；旧运行显示“历史运行” |
| 失败恢复 | 显示配置内项目未完成；修复条件后可新建运行重试，原失败记录保留 |
| 导出 Excel | 四个工作表：任务与范围、逐项检查、依据与原文、复核记录 |

“复核完成”表示每项均有明确处置，可以包含暂无法确认；不表示产品合格、整改关闭或允许放行。导出保留未复核项目与未配置范围；外部输入作为单元格文本写入，避免被作为公式执行。

## 实测结果

本轮使用1份构造报告、12项作者拟定参考标注，重复运行3次。重复运行是稳定性检查，仍只有1份独立报告。专业标注尚未完成。

| 指标 | 结果与解释 |
| --- | --- |
| 自动测试 | 62个测试方法通过，其中新增AI Work 23个；另有数值边界子用例 |
| 配置内10个单元 | 5项未发现问题、2项按记录比较不符合、3项证据不足 |
| 一致性项 | 2项冲突；与超限不是4个独立缺陷的统计 |
| 参考结果对照 | 每次12项均与作者草拟预期一致；3次共36次对照 |
| 必要来源与记录 | 36次对照均包含预期依据、报告页及对应记录ID（适用时） |
| 模型请求 | 0；本次使用规则与计算，不产生新增模型请求费用 |
| 检查引擎耗时 | 三次约4.62 / 2.59 / 2.60 ms；不包含上传、解析、用户核对、复核和导出，不能作为端到端业务耗时 |

实际输出保存在 [ai-work-review-final-v0.2.json](https://github.com/zhujy9413-commits/powerbank-rag-agent/blob/main/eval-results/ai-work-review-final-v0.2.json)，包含三次原始结果、输入快照、来源、草拟参考对照与引擎源码摘要。

### 关键行为核对

| 情形 | 观察到的行为 |
| --- | --- |
| C1 R02写0.68 s | 换算为680 ms，再与模拟500 ms比较；不比较0.68和500 |
| C1摘要S01为80 ms | 绑定C1响应字段；同时保留摘要与明细，未因A1也为80 ms而串端口 |
| C1 R04为5.31 V | 根据已选RevB闭区间作比较；保留报告自填RevA版本冲突 |
| C1温度为3?.0 | 停止数值比较，标证据不足；不猜测模糊位 |
| C1外观与恢复方式横线 | 缺证；不声称实际未测试 |
| PDF内F01要求全部通过 | 作为来源文字保存；不改变规则、范围或引用 |
| 复核排除发现 | 原始不符合仍在，人工处置另外保存 |
| 重复请求 / 旧版复核提交 | 运行幂等；复核版本冲突返回409，不静默覆盖 |

已通过页面检查确认范围、开始检查、记录“暂无法确认”、查看证据与刷新恢复。Excel四张表已用独立读取工具检查数值与文字并渲染检查；未验证 Microsoft Excel 原生客户端操作。基线导出无公式，计算已固定在运行快照中。

开发过程中修正了首次接入时页块缺少排序元数据，以及测试辅助方法与框架同名的问题；上述通过结果来自修正后的完整回归。没有删改原有样本参考标注来适配输出。

## 与完整PRD的关系

| 原PRD要求 | 当前进展 |
| --- | --- |
| 确认输入、依据与预期清单 | 在固定模拟模板与规则范围内实现 |
| 数值比较、缺证、冲突、复核与导出 | 在此范围内实现并验证 |
| 版本修订、权限、幂等与失败可见 | 本机身份与任务所有者范围内实现 |
| 任意报告布局、OCR、波形和复杂条件等价 | 未实现；不在当前支持范围 |
| 可编辑适用性与排除理由 | 当前为固定清单；完整配置尚未实现 |
| 真实规则白名单、专业复核、企业登录 | 尚未具备，不宣称完整MVP或生产验收通过 |

下一步应扩充受控模板变体与异常输入，再验证字段提取覆盖和条件冲突。获取合法真实资料并落实专业复核后，才能扩大规则范围及开展人工耗时对照。

## 运行与复现

使用Python 3.9及以上。知识问答可不安装PDF依赖；AI Work需安装已验证的pypdf版本。

```bash
python3 -m pip install -r requirements-ai-work.txt
python3 -m app.knowledge_assistant.server --open
python3 -m unittest discover -s tests -v
python3 scripts/evaluate_review.py --output eval-results/ai-work-review-new.json --xlsx outputs/ai-work-new/report-review.xlsx
```

结果脚本拒绝覆盖旧文件。`.local/assistant/reviews.sqlite3`仅在本机保存任务、PDF、输入修订、运行及复核；未同步数据库、密钥或模型业务空间地址。GitHub和飞书仅同步明确的模拟样本、源码、说明与测试产物。
