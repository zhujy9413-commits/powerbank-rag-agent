## 使用与标注约定

每组内容报告含2个开发场景和4个留出场景。按报告家族分组，不把同一底稿的数值改写分到两边。开发可调试；留出材料在候选链路冻结后制作，先校验原文与参考组，再冻结哈希，首次全量运行前不得查看得分。属于同作者时间留出，不能称外部独立评测。

要求来源与报告来源分别标注必要证据组，同义且充分的多个引文可列为同一组的替代项。已有字段足以证明同一事实时，不强行要求重复叙述，否则会人为制造基线遗漏。标签及参考答案只供评分器读取。

S01/S02/S03为零容忍门禁；R01/R02/R03为检索门槛；M01为说明技术及人工验收；P01为时延；C01为成本。编号含义及具体阈值均见方案。内容场景统一应用全部九项指标；A0/A1/A2的模型指标记不适用，不填0。

## R02评分执行核对

R02名称为“前5条实际返回精度”，公式为相关有效槽位数/m，m=min(5,原始返回条数)。正例m=0记0；少返回不再补空槽，门槛仍是每个候选组、每个留出轮次、每个命名空间的等权宏平均≥80%。A0无补充排序记不适用；A3/A4沿用A1/A2的检索日志。应用不得读取评测qrels。以下是评分器契约核对，不是新增的开发/留出样本，也不计入48个场景。

| 核对项 | 必须满足的口径 |
| --- | --- |
| 正例短返回与空返回 | 2条相关返回=2/2；1条相关返回=1/1但仍检查R01/R03；明确已执行的空返回/失败记0 |
| 重复与错误 | 同ID或同源同版本同来源角色同原文重复的后续槽位记0；未知ID、越权、错任务/角色/版本/定位/条件/引句占槽记0，控制异常另外登记 |
| 种子与扩展 | 评分输入保留最终原始种子顺序，不在评分前去重或过滤错误；预注册扩展不计R02，自然检索到的相关表头可作种子 |
| 排序完整性 | 超过5条只计前5，保留完整列表并标记配置违规；不能以截断后的精度宣布实验有效 |
| 独立相关性标签 | 当前开发qrels含248个查询/来源组合，245正例、3报告缺证负例；所有授权候选均预先有0/1标签，无可选相关补标，不把相似分数当真值 |
| 工况与证据角色 | 预登记contrast_only仅支持指定工况对照，禁止替代当前测量；背景说法只对背景核对相关，不能补齐缺证；报告RevA不能当选定RevB依据 |
| 负例收敛 | 不进入精度宏平均；原始噪声可被检索但须拒绝为依据；最终evidence_insufficient、接受证据为空、无伪造缺失证明、不宣称物理试验未做；正确收敛率要求100% |
| 缺失与争议 | 缺运行记录/日志、未标注或争议标签记未完成，保留固定正例/负例查询分母；不以部分均值通过，不用另一来源或另一轮补齐 |
| 联合验收 | R02数值达标仍须R01/R03完整性及S01至S03等门禁全部满足，不能以一条高精度证据替代完整报告 |

正式运行前，将[当前协议](../../data/ai-work-rag-gain-v0.2/protocol.json)、[开发种子qrels](../../data/ai-work-rag-gain-v0.2/qrels-dev-v0.1.json)、评分器和语料哈希一并登记。留出qrels须随32个留出资产制作及复核后冻结；当前未制作，不登记为已完成。
