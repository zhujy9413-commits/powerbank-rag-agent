# AI Work RAG 增益验证方案

版本v0.1 · 2026-10-29 · 实验范围与验收口径已确定，实验未执行。

本实验验证两件事：补充语义检索能否减少评审证据遗漏，以及模型说明能否帮助评审人员理解已有发现。保留现有完整规则链路，用五组配对对照分别识别检索与生成的贡献。只有达到证据、安全、时延和成本门槛的能力才进入后续接入；没有增益时保留现有方案。

当前已交付本方案及[评测清单](rag-gain-evaluation-checklist-v0.1.md)，并完成[16个开发场景材料](rag-gain-dev-sample-pack-v0.1.md)及[材料核验](rag-gain-dev-material-audit-v0.1.md)。剩余32个留出场景尚未制作，候选代码、模型及Prompt尚未冻结，未发起实验模型请求、未获得实验分数。下列数值是本轮内部工程验收门槛，不是行业标准、既有实测或收益承诺。

开发材料的静态预检发现，R02固定空槽分母在当前必要组标签下使80%精度门槛不可达；[核验报告](rag-gain-dev-material-audit-v0.1.md)已记录修订建议。原指标尚未修改，正式计分前须解决相关性标签与分母口径。

内部智能客服在2026-10-27验证过百炼`qwen-flash`和`text-embedding-v4`，也记录过引用、角色和语义问题；这些结果不作为AI Work的效果分数。该记录证明历史接入，不保证当前模型别名、服务端版本或价格未变。[历史接口验证](../internal-assistant/live-validation-v0.1.md)

现有依据块较少且固定映射可能已充分覆盖任务。不能去掉映射或全页扫描制造较弱基线，也不能强迫系统重复引用等价叙述来制造“遗漏”。实验须允许证据覆盖达到上限、没有必要增加语义检索这一结论。

## 对照组与可归因比较

基线固定为提交`2a582e251f67aee7a9189723a095c22aba8f079e`，页面v0.4.3、解析/规则v0.4。引擎摘要及源码、原知识包摘要写入[机器协议](../../data/ai-work-rag-gain-v0.1/protocol.json)。每份输入先生成一个共同确认快照，五组使用同一快照；新增输出保存在独立实验记录中。

| 组别 | 保留原链路后增加的能力 | 用途 |
| --- | --- | --- |
| A0 现有完整基线 | 无 | 衡量真实现状；固定映射、页排序、全页扫描和原证据全部保留 |
| A1 关键词补证据 | 相同切分上的BM25补充检索、模板说明 | 对照“增加证据检索步骤”本身的收益 |
| A2 混合检索补证据 | BM25与向量融合补充检索、模板说明 | A2对A1识别语义检索贡献，同时与A0比较实际增益 |
| A3 关键词与模型说明 | A1证据上生成评审说明 | A3对A1识别生成贡献 |
| A4 混合检索与模型说明 | A2证据上生成相同格式说明 | A4对A2识别生成贡献；A4对A3观察语义检索对说明的影响 |

五组都保留原系统结果与原证据，候选证据和`assisted_explanation`独立保存，不改写原`explanation`。比较不可变的检查载荷及哈希，排除运行时间、动态依据核验时间等非业务差异。模型只读取本次授权证据和已完成的规则事实。

A1—A4共享分块、查询、过滤、上下文扩展及证据预算；A3/A4共享Prompt、模型和采样配置。不能只给混合组补上已知必需依据，不能让任何应用组读取评分标签。A0原有资料关系映射不算模型推理能力。

## 检索与生成配置

要求证据限定在已确认的模拟依据快照，报告证据限定在当前任务。先按授权、来源角色、发布版本和适用对象过滤，再检索、送Embedding或模型；历史停用/撤权路径沿用G01门禁。引用返回前再次核验。未明确的内容条件保留未知或未验证，不能因相似分数变为已确认。

每项查询仅由型号、端口、项目、已有条件和所需字段构造，不使用case_id、参考答案或期望引文。要求与报告各返回5个种子片段；BM25/向量各取前12候选，默认等权RRF、常数60。同分按稳定来源ID排序。参数可在开发集调整，留出前必须冻结；评分始终按每类top-5计算。

上下文扩展每个种子最多增加1条预先关联的表头或脚注片段，A1/A2共用相同规则，不依赖参考标注。扩展片段单独登记，计入上下文及费用；同时报告扩展前的原始召回率和扩展后的必要证据组覆盖，不能把额外片段伪装成原始top-5。

每份内容报告预设20个有权限的干扰片段，总索引上限80块，单次报告最多12个查询。干扰属于构造实验条件，不代表公司真实资料规模。无权限片段只用于本地过滤门禁，不得送服务方。材料制作时登记实际块数和干扰密度，不能依分数删改。

模型输入上限12000字符，按检查项顺序组织、去重并保留整组证据。超限须记录被截断来源；缺少必要Prompt证据时该项回退模板，仍计入分母。输出仅允许检查项身份、原状态引用、说明、引用和限制等约定字段，拒绝新增判定字段。引文必须属于本次原文并保留来源角色、版本和页/章节。

优先复用现有百炼适配器；历史验证模型ID仅作候选。执行前核验可用模型、供应方返回的模型身份/别名、向量维度、价格和请求限制，写入冻结记录。当前35秒的共用HTTP超时不等于本实验已满足时限；实验适配层须实现单次生成20秒、总任务45秒、最多一次校正。失败回退模板，全部尝试留存。此处均为待实现约束。

## 指标定义与固定验收门槛

验收以24份内容留出为主，32个留出场景的相关安全断言全部检查。每轮24份各有10个固定检查单元，但它们来自24个报告家族；不能当成240份独立报告。新增一致性项、解析诊断、无证据项各自登记。三次重复不扩充独立样本数。

| 编号 | 验收指标 | 门槛及口径 |
| --- | --- | --- |
| S01 | 授权 任务 版本及来源角色 | 所有适用断言通过；越权片段进入候选、Prompt、服务方载荷或导出次数为0。停用历史与新检查分开处理 |
| S02 | 原系统结果与历史保护 | 五组原检查载荷及原证据100%一致；数值、条件、缺证、失败、未配置和历史处置不得被新增链路覆盖 |
| S03 | 接受的引用身份及定位 | 授权、版本、来源角色、页/章节和逐字引文100%通过。对外接受的伪造或不支持引用为0；原始错误仍记录 |
| R01 | 必要证据组召回@5 | 要求与报告分开计算，宏平均各≥95%，A2各不低于A1；扩展前原始召回另列 |
| R02 | 补充候选精度@5 | 要求与报告分开计算，宏平均各≥80%；无关、错误端口、错条件及角色混用不得算相关 |
| R03 | 报告级完整证据与净增益 | A2每轮≥22/24份完整；对A1和A0分别净增至少3份；A0原已完整的报告退化为0；三轮均满足 |
| M01 | 说明技术及人工可用性 | A3/A4分别每轮首次结构/引文有效≥23/24，最终有支持的非模板说明≥23/24；人工盲评三项全满足≥22/24、偏好候选≥16/24。危害性错误接受为0 |
| P01 | 全链路时延与失败终止 | 正常内容报告首用P95≤30秒、既有任务P95≤15秒；单次生成≤20秒、总任务≤45秒、校正≤1次。失败计入时延和失败率 |
| C01 | 成本与止损 | 各候选平均增量可变费用≤0.20元/报告；本轮总额≤100元，外部请求≤2500次，任一上限先触发即停止并记未完成 |

R01的单查询分母是冻结的必要证据组数。top-5种子及预注册上下文完整覆盖某组任一等价方案，且身份、定位及条件核对合格，才计该组命中；再按有正例的查询取宏平均，两类来源不合并掩盖问题。补片数量和扩展前后差异另报。查询无可用证据时不定义召回率，单列数量，要求正确缺证/拒答率100%；不能用无证据查询填0或1抬高平均。

R02按返回的补充种子片段计算相关比例，分母为`min(5,当前授权候选数)`，空候选正例记0，少返回仍保留相应未命中槽位；负例查询单列正确收敛。相关性需与原文、对象、来源角色和冻结参考组对应，不能只核对ID存在或取Embedding相似分数。

R03使用实际交付给评审人的A0证据与已接受补充证据，而非只看中间召回列表。全部必需组覆盖、缺证项正确保持缺证、冲突双方及限制保留才算整份完整。净增份数=新增完整份数－退化份数，3/24等于12.5个百分点，不写成预期已实现的提高比例。如果A0已完整≥22/24，净增3份不可能达到，记基线上限/未证实增益，保留A0；不得据此事后修改样本或门槛。

M01把原始结构错误、校正后错误、被拦截的语义问题和模板回退分别计数。成功回退保证可用性，不算模型解释增益。可支持说明须由冻结事实和实际Prompt证据逐条核对，开放性解释未经复核记待定。至少1位未参与调试的评审阅读者对24份报告匿名配对评价“含义与限制正确、能定位依据、能理解下一步”，三项均为是才算完整；并列偏好不计候选胜出。A3对A1、A4对A2分别评，不以同一个生成模型自评作为通过依据。当前阅读者未指定，人工可用性保持待验。

P01首用从上传开始，包含共用解析、报告切分/新增索引、检索、生成、校验及必要持久化；既有任务复用索引另测。共用解析只测一次并归入各组，不重复制造输入差异。首用测量不复用查询缓存；初始知识索引、冷/热状态和逐次阶段耗时都单列。按每个候选组每轮24个报告终止耗时，用nearest-rank的P95即第23小值；失败不移除。离线故障场景另验45秒终止，不混入正常P95。

C01含报告及查询Embedding、全部生成尝试和必要新索引，初始知识索引费用按实际混合组运行数摊销，同时单列原始总额；整体账本不重复摊销。服务方未返回usage时记未知并保留请求身份，不填0。执行前依据官方当前价格登记输入/输出/向量计费口径，预计超预算时在接触留出结果前修改协议版本。100元是方案止损上限，不是本轮支出授权或实际费用；当前没有付费请求。

## 结果决策与降级

三类结论分别记录。检索技术通过要求S01—S03、R01—R03、P01、C01全部满足；说明技术通过要求相应生成组的S01—S03、M01技术项、P01、C01满足，人工项未验时不能宣布可读性增益。没有满足净增条件的能力不因“已接模型”而默认采纳。

任一越权、伪造证据被接受、规则结果被改写或文档指令覆盖系统流程，候选立即停止接入并保留失败。Embedding不可用时可退到关键词，必须标明降级，不能记作混合检索成功；模型超时或校验失败时展示原结果与模板说明，原始失败及费用不丢失。预算停止、标签争议、模型版本漂移或缺关键日志均记未完成/不可判断，不计算通过结论。

可以只采纳关键词补证据、只采纳语义补证据，或保持A0；模型说明另作决定。有限构造样本只支持本轮范围内的技术判断，不能据此声称公司漏检减少、节省工时或降低改板率。实际业务收益仍须专业复核及真实使用者对照。
