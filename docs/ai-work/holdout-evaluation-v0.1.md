# 07-新样本留出评测与问题清单

v0.1 · 2026-10-28。AI Work原型仍为v0.2，本轮未修改应用代码。

本轮完成20份新模拟PDF的核验、冻结和首次评测。冻结期望满足12/20个场景，文字记录匹配181/193条；未达到扩大输入范围的条件。重点发现未知编号、同页图片和局部条件被遗漏后，部分条目仍显示“未发现问题”。原始失败完整保留，没有用这批结果修改解析器或调整期望。

## 评测范围与独立性

评审对象仍为虚构PB-DEMO-01整机、A1/C1端口、5 V输出、单口的已有短路保护记录，沿用原有模拟知识依据。报告、数值、规格均为构造材料，没有使用企业历史资料，也没有运行硬件实验。

20份PDF、40页是在上一轮调试结束后新建；与历史PDF的文件摘要不重复，与24份开发样本的记录编号不重复。测试包含新数值、新位置和新组合，部分问题类型仍与开发集相同。

这属于**代码冻结后的新样本留出评测**。设计者知晓现有实现，样本和标注仍由同一项目作者拟定，不属于盲测、外部独立测试或专业验收。样本是定向异常探索，并非随机抽样；共享基础布局和部分数值，不能据此推断真实报告总体准确率或业务收益。

## 优先处理的问题

本轮不进入修复，先保留首次结果。以下优先级用于下一轮实施，并未把所有问题都列为P0。

| 优先级 | 问题 | 依据与下一步 |
| --- | --- | --- |
| P0 | 未识别记录锚点可能静默遗漏 | HO-04补充异常被跳过；扩大候选审计，未知编号也需保留原文和阻塞。HO-05补充覆盖状态问题 |
| P0 | 混排图片未核验却被视作文字页已覆盖 | HO-07；识别可能包含记录的图片区域，未核验时提示并停止相关单元，不必先承诺完整OCR |
| P0 | 脚注/局部条件遗漏，错误继承全局条件 | HO-08/09；存在未绑定条件时先核对作用范围，不能默认5 V适用 |
| P1 | 未支持条件维度与样机对象 | HO-14/15；显式保留负载、样机差异，无法判断同条件或同对象时保守降级 |
| P1 | 跨行摘要与孤立单位诊断不一致 | HO-17；统一片段归属，避免将摘要单位错误绑定其他项目 |
| P1 | 评分协议对等价正确结果过窄 | HO-17；下一轮冻结前应允许正确跨行识别与保守降级两种合理结果，本轮标签与分数保持原样 |

HO-04/07/08/09共4个场景、8个核对单元，在冻结期望要求停止时仍显示“未发现问题”。其中部分是文字完整性项，不能称为8次数值计算错误。该现象比单纯漏提取更影响评审可靠性；文字匹配181/193无法覆盖这类条件遗漏风险。

HO-14/15涉及当前未配置的负载和样机维度，是扩展输入下保守处理能力的缺口，不能据此声称本轮已实现了相应条件规则。

## HO-17的标注复核说明

冻结断言要求出现`SUMMARY-MISSING=证据不足`，没有容纳实际正确跨行提取。首次结果中，摘要`0.137 s`被识别，与137 ms明细一致，生成了`SUMMARY-A1=未发现问题`。仅因该结果不叫SUMMARY-MISSING就判失败，评分口径过窄。

同时，逐行审计又把摘要的`s`当作孤立单位，绑定到前页A1恢复方式，使该项停止检查。摘要提取与单位诊断的片段归属不一致，是另一个需要处理的问题。

因此保留原始12/20和36/58，不把8个未满足场景统称为8种系统缺陷，也不在看到结果后改标签重算“更好”的分数。该复核仍为同作者审阅，专业裁决待完成。
