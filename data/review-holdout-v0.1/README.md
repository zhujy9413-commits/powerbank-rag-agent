# AI Work 新样本留出评测包 v0.1

2026-10-28。全部为软件构造的模拟资料。被测范围仍是PB-DEMO-01整机、A1/C1端口、5 V输出、单口的已有短路保护记录。

## 冻结与独立性的口径

被测代码固定为提交`cde690ee6fbf6b60a3ef3c7444eeacba3c28cafb`。20份新PDF、期望标注、评分脚本和核验记录在首次运行被测引擎前单独提交。运行时通过`git archive`取出指定提交的应用及知识样本，在临时目录子进程中执行；子进程只接收PDF路径与样本ID，不接收期望、答案或评分标签。

本包未参与前一轮调试。本轮作者没有根据新样本运行结果修改被测代码、PDF或期望。样本设计知晓现有实现，仍由同一项目作者构造，**不属于盲测、外部独立测试或专业验收**。这是一轮代码与输入冻结后的时间留出评测。用例是定向异常探索，不是随机抽样，样本之间共享基础数值和布局，不可推断真实报告的总体准确率或置信区间。

现有24份PDF开发集已用于调试，不纳入此次分数。本包文件摘要及记录编号均与该开发集分离。部分故障类型有意重复，新增数值、位置或组合，验证迁移边界；不能声称20种问题全部前所未见。

## 文件与固定分母

- `cases.json`：20份PDF的路径、SHA-256、预先拟定的文字/图片记录与行为期望。
- `preflight.json`：不调用评审引擎的核验记录、实际页文字、图片数量和渲染日志。
- `visual-review.md`：渲染与标注核验结论。
- `freeze.json`：被测提交、语料摘要、环境及冻结资产SHA-256；在首次执行前入库。
- 原件位于`output/pdf/review-holdout-v0.1/`，共20份、40页。

| 口径 | 固定数量与含义 |
| --- | --- |
| 场景 | 20个；分别要求正确提取、可见诊断、停止比较或拒绝，满足期望不等于报告通过 |
| 明确标注的文字记录 | 193条，覆盖19份可读取文件；包含当前语法可能不支持的编号和换行字段，不能因解析失败缩减分母 |
| 图片内记录 | 1条，单独验证覆盖提示和受影响单元停止比较；不混入文字识别分母 |
| 加密文件 | 1份、10条原始文字记录；因预先定义为应拒绝输入，不计入193条文字分母，单独检查特定拒绝原因 |
| 行为断言 | 58项，包括35项要求停止比较的断言；部分还明确要求`not_checked`状态 |
| 必须出现解析诊断 | 5个场景；只有`needs_review`且存在具体诊断才满足，统一的专业待复核提示不算 |

文字识别采用多重集合比较，要求记录ID、端口、字段、原始值一致。仅对空白及NFKC进行标准化；不通过引擎输出来改标签。多提取、遗漏分别保留，重复值不能充数。字段名跨行等不支持布局允许正确提示并保守停止，该场景可满足行为期望，但遗漏仍计入193条文字指标。

## 预先拟定的场景与验收

| ID | 场景 | 关键期望 |
| --- | --- | --- |
| HO-01 | 新数值、响应/电压/温升边界组合 | 10项按模拟规则未发现问题 |
| HO-02 | 边界外的新数值 | 6项按记录比较不符合 |
| HO-03 | 全角条件、字段别名、秒/毫秒混排 | 摘要和明细同条件且数值一致 |
| HO-04 | 额外TC编号记录为913 ms | 提示未完整解析，A1响应停止比较，不能只取137 ms |
| HO-05 | 全部采用五位数字记录ID | 提示不支持或未完整映射，相关10项未检查 |
| HO-06 | 恢复电压字段名跨行 | 正确提示不完整，A1恢复电压未检查 |
| HO-07 | 文字页附图片记录927 ms | 识别到尚未核验的图片区域，A1响应停止比较 |
| HO-08 | 脚注说明某条实际为12 V输入、多口 | A1响应停止比较，不套用全局5 V |
| HO-09 | 表内局部条件为12 V | A1的5项停止比较，不套用全局5 V |
| HO-10 | 行内同时写5 V和12 V | 条件矛盾，A1响应未检查 |
| HO-11 | 行内角色明确未记录 | C1响应未检查，不以全局输出补齐 |
| HO-12 | 同一字段同时有5 V及12 V记录 | 不挑选或合并数值，A1响应未检查 |
| HO-13 | 明细环境明确、摘要环境未知 | 摘要证据不足，不认定同条件数值冲突 |
| HO-14 | 明细/摘要负载分别2.0 A和0.5 A | 未配置该条件维度时停止一致性判断，不认定同条件冲突 |
| HO-15 | 同字段来自SN-A及SN-B | 对应关系未明确，证据不足，不直接认定同对象数据冲突 |
| HO-16 | 跨页，条件在记录之前 | 条件绑定不明确时提示并停止比较 |
| HO-17 | 摘要数值、单位跨行 | 不得误宣称摘要一致；未支持时明确证据不足 |
| HO-18 | 单位只在列标题声明 | 未还原单位时停止数值比较 |
| HO-19 | 仅一条记录填写完整条件 | 该条可核对；条件不能泄漏给其余9项 |
| HO-20 | 加密PDF | 明确以加密不支持为由拒绝，不把任意异常算正确拒绝 |

HO-14/15刻意检查当前未覆盖的负载、样机维度，应理解为对保守降级的探索，不能据此宣称已实现这两类条件解析或存在真实标准的对应阈值。

模拟数值期望来自`SYN-NORM-RESPONSE`、`SYN-SPEC-PB01-RevB-REC`、`SYN-NORM-TEMP`及相应外观/恢复记录规范：响应≤500 ms，恢复电压4.75至5.25 V（含边界），温升≤12 K。它们不是国家标准或实际企业要求。条件不明确、超范围或对象不可对应时的期望来自保守评审约定，专业核实待完成。

## 复现与保留

验证依赖为Python 3.10及以上及`requirements-dev.txt`，当前环境为Python 3.12。样本原件已入库，无需重新生成。构造脚本不覆盖已有样本；评分脚本不覆盖已有结果。

```bash
python3 scripts/evaluate_review_holdout.py --output eval-results/review-holdout-reproduction-new.json
```

`freeze.json`必须已经存在于当前HEAD且资产摘要一致。评测运行固定Git提交，即使以后工作区代码修复也不会改变本轮被测版本。首次结果完整保留；本包一旦用于修复即转为开发/回归集，下一轮独立留出须重新准备样本。
