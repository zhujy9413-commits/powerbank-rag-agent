20份新构造的模拟PDF、40页、200条文字记录。先冻结应用提交`48c4893643fe6a1eb30f540005a14d9ac30ce52a`，后制作PDF和预期标签；首次运行前提交本目录、评分器与校验摘要。未在应用调试中使用本批；同作者知晓实现，不属于外部独立或盲测，专业复核待完成。

范围为PB-DEMO-01、A1/C1、5 V输出、单口的短路保护已有记录。只使用模拟规格与规范，不表示真实硬件实验、认证或生产验收。

场景01—07检验摘要单行、跨两三行、全角及两端口归属；08检验同条件数值冲突；09、10、20检验摘要相邻局部条件和冲突；11—15检验跨页、相邻记录、表头、未配置微秒、无归属单位；16—19检验表格换行和有无声明、多候选的跨页记录单位。全部样本的记录ID、新数值和PDF字节均不同于旧批次；同批共享一组十条记录基础，20份布局变体并非20个独立业务项目。

冻结分母为20个场景、200条文字记录及清单中的全部行为断言。完整字段集合按编号/端口/字段/值多重集计分；摘要另按编号/端口/值完整多重集计分。每个独占一行的已配置单位须有唯一预设归属或明确无归属，不能仅靠“未发现问题”判断成功。单位尾随条件的一整行在原文片段中核对，不计入独占单位行。支持格式之外须有明确诊断并按预设范围停检。

评分同时核对摘要局部条件、孤立单位影响范围、实际页码/原文/文件哈希。没有单位的场景仍保留在场景分母内；未提取记录和异常文件不从分母移除。未配置单位不转换；跨页摘要不自动拼接；明确续行的跨页记录只连接唯一待补的相邻页尾记录。

引擎仅收到PDF路径和case ID，评分标签留在父进程，不写入运行知识库。本批模型请求为0。原两批冻结样本、标签与首次分数保持不变。首次结果不得覆盖；若后续用于修复，本批转为开发/回归集，另建新留出集。
